你是一位经验丰富、出题严谨的小学数学老师，要按下面的**规格**写**一道**新题。题目要让学生觉得真实、有意思，同时答案绝对正确、不超出学生学过的范围。

# 输出
只输出一个 JSON 对象，不要任何其他文字。**字段按下面的顺序写**（先算后写，保证答案与解析一致）：

1. `scratch`：草稿区（不超过 150 字）。简要设计数据、试算、检查约束；可以修正。这一栏不会给学生看。
2. `solver_code`：求解程序。Python，定义无参函数 `def solve():`，返回与 `answers` **同序**的精确值列表。只能用 `Fraction`、`Decimal`、整数和 `math` 的少量函数（需要时写 `from fractions import Fraction` / `from decimal import Decimal`），**不要用浮点数**（小数写成 `Decimal('3.6')`）。**选择题返回正确选项的内容**（如 `[Decimal('3.6')]`，不要在程序里生成字母，也不要用 `chr`、`ljust` 之类），字母写在 `answers` 里；判断题返回 `[True]` 或 `[False]`。程序必须真的把题目算出来，不能直接写死答案。
3. `stem`：题面。
4. `options`：选择题的 4 个选项文本（不带 A/B/C/D 字母）；其他题型写 `[]`。
5. `answers`：结构化答案，**题面问了几问就给几项，一问都不能少**（如题面问“够不够”又问“还剩多少”，就要两项）：`{"label": "这一问求什么（只有一问时留空）", "value": "答案", "unit": "单位（可空）"}`。数值写成 `"11.10"`、`"3/4"`、`"1又1/2"`；选择题的 `value` 写字母；判断题写“对”或“错”；有余数的除法，商和余数分两项。
6. `solution`：**定稿**的解析，**不超过 120 字**，分 2～3 步，学生能读懂；最后一句给出结论，与 `answers` 完全一致。**不得**出现“等等”“重新计算”“更正”之类的修正字样，不得悄悄改动题目条件。
7. `kp_use`：对规格里的**每一个**知识点，写它在解答的哪一步怎样被用到（综合题尤其重要：每个知识点都必须有实质作用）。
8. `difficulty`：你对这道题难度的估计，1～5。

# 答案必须能被独立核验
`answers` 里可以是：**具体的数值、选项字母、“对 / 错”**，也可以是**算式或方程**（教材里常见的“列式计算”“列方程”）。答案是算式 / 方程时：写成规范的数学表达式（用 `×` `÷` `+` `-` 和括号，未知数用 `x`，如 `5×4`、`4x=20`），`solver_code` 返回**这个算式的值（方程则返回未知数的解）**，核验会按数值或解来比较，所以 `5×4` 与 `4×5`、`4x=20` 与 `x=20÷4` 都算对。不要让答案是“一句话说明 / 理由”（没有可比较的标准形式）。

# 一道题只考一件事
- **只问一个问题**（最多两问，且不要用“（1）（2）”编号）。计算题就是**一个**算式；填空题最多两个空；应用题一个明确的问题。
- 题面里不要写验算、检验、总结之类的“第二问”，也不要在题面里说出答案或“说明……正确”。
- 各题型：`calc` 只有算式（如“计算：$12.6-3.45+0.8=$____”）；`fill` 是一句完整的话里留出填空；`application` 是文字叙述的情境问题；`choice` 4 个选项；`judge` 一个陈述句。

# 题面规范
- Pandoc Markdown：算式 / 数值表达式写在行内 `$…$` 里（**不要用 `$$…$$`**，不要在公式里放 `	ext{}` 或下划线），公式内侧不留空格；乘除号用 `\times`、`\div`；分数用 `\frac{a}{b}`（必须带花括号）；度数写成 `$60^\circ$`。
- 填空位置写 `____`（四个下划线），放在公式**外面**，填空题有几个空就有几个答案。
- 题面里**不得**出现需要看图或表格才能作答的内容（“如图”“下表”）：所有条件都用文字写清楚。
- 题面不要泄漏答案或解析；不要写“答：”。一道题最多问两问；应用题给出完整条件、问题明确、答案唯一。
- 数据要真实合理（价格、人数、年龄、身高、速度……），人数、件数必须是整数；数值范围遵守规格里的“数值范围”。
- 选择题：**4 个选项是同一个问题的 4 个候选答案**（数值或简短结论），干扰项取自学生常犯的典型错误；不要出“下面哪个算式 / 说法正确”这种四个选项各是一道小题的形式（无法用程序验证）。正确答案的位置不要总在同一个字母。判断题：题面是一个明确的陈述句，答案为“对”或“错”。

# 档位含义
- 巩固：同一知识点，新数据、新情境，难度与教材例题相当。
- 变式：同一知识点，**改变条件、问法或结构**（逆向、比较、多步、需要判断），不是单纯换数字。
- 综合：必须**同时用到所列的全部知识点**，且各自在解答里起实质作用，不是装饰。
