# M4 感知（图像预处理 / perceive / 学生上下文 / 防雷同）评测规格

范围：让教师**拍一张练习册 / 作业 / 试卷的照片**，系统读出每道题、判断学生学到哪、据此出题，并保证新题不是照片里那些题的翻版。包括：①**图像预处理**（方向、尺寸、质量检测）；②**`perceive` 阶段**（视觉模型逐题转写 → 知识点映射 → 难度与题型估计）；③**学生上下文**（照片 → 年级 / 课时 / 知识点 / 难度，约束后续生成）；④**防雷同**（照片里的题 = 参考题，新题不得照抄）；⑤**非数学 / 模糊 / 空白图的友好拒绝**；⑥**转写低置信时的确认检查点**。

设计依据：[PRD FR-2 / S3](../../docs/prd.md)、[architecture §5](../../docs/architecture.md)（`perceive`、`ReferenceSet`）、[evaluation §3.2](../../docs/evaluation.md)。指标见 [metrics.md](../../docs/metrics.md) 的 B4、B5、B6、D 组"单张照片识别 ≤ 15s"。

## 1. 失败模式与检测手段

| # | 失败模式 | 教师感受 | 检测手段 | 指标 |
|---|---|---|---|---|
| 1 | **数字 / 符号 / 单位读错**（0.7 读成 0.07，×读成+，3.6 读成 3.8） | 照着错题出题，最伤 | 与人工标注逐题比较（归一化后）：题级完全一致率、字符错误率、数字序列不一致单列为致命错误 | B4 |
| 2 | **漏题 / 合并 / 拆分**（一行三道口算被读成一道） | 题量不对 | 标注题与识别题做最优配对：召回（标注题被找到的比例）与精确（识别题有对应标注的比例） | B4 召回 / 精确 |
| 3 | **把不是题的东西当题**：页眉（"第二周 周一"）、二维码、"算法整理"示范、手写作答、反面透印（纸张薄，背面的字淡淡透出来） | 题里出现莫名其妙的东西 | 精确率里的"多出的题"逐条归因（示范 / 透印 / 手写 / 页眉）；示范区与透印另设专项用例 | B4 精确、P3 |
| 4 | **图表题读错或丢图**：折线图 / 条形图 / 表格 / 几何图（含数据与角度）被忽略或读错 | 图题出不了或出错 | 有图的题必须标 `has_figure` 并给出文字描述；描述里的关键数据与标注比对（只对少数图题标注） | P4 |
| 5 | **知识点映射错**：照片是"小数的性质"，上下文却成了"小数加减法" | 新题跑偏 | 题 → 知识点：top-1 / top-3 命中（页面级与题级） | B5 |
| 6 | **难度、题型估计偏差** | 新题太难 / 太简单 | 与标注难度（1～5）的平均绝对误差；题型一致率 | B6 |
| 7 | **该拒的不拒**：非数学页、英文页、风景照、全黑 / 全白 / 严重模糊图被硬编出题目 | 乱出题，丢人 | 负例集：判定必须是"不可用"且不产生参考题；回复是教师语言、给出下一步建议（"请对准一页数学题，光线充足"） | P5（拒识率） |
| 8 | **误拒**：正常但略斜 / 偏暗 / 有反光 / 有手写的页面被拒 | 好好的图用不了 | 变体集（旋转、透视、模糊、低光、反光、遮挡、手写）上的"可用"率 | P6（误拒率） |
| 9 | **低置信不告知**：数字看不清却照读，且后续按错数字出题 | 静默出错 | 低置信 / 有不确定标记的题触发确认检查点；评测：转写错误的题里，模型自标不确定（或置信度低）的比例；以及"标了不确定但其实对"的比例（打扰度） | P7 |
| 10 | **新题照抄参考题**：同数字同情境，或只换个数字 | 学生做过的题又来一遍 | 确定性：与参考题的相似度（形状 + 数字）不低于阈值的新题数；创作阶段的新颖度检查拦截，评测统计漏网数 | P8 |
| 11 | **照片与一句话要求互相覆盖**：说"照这页再出 5 道"却只出了 1 道，或范围被一句话里的年级覆盖 | 没按我说的来 | 用例：照片 + 一句话 → Brief 的题量 / 范围 / 来源标记符合预期（照片来的范围标 `inferred`，用户明说的永远优先） | P9 |
| 12 | **识别太慢** | 等不起 | 单张照片转写时延 | D（≤ 15s p50） |
| 13 | **图片内容当指令**：页面或手写里夹带"忽略以上要求……" | 被劫持 | 注入用例：模型输出只被当作数据，题面里的指令不改变路由 / 范围 | 安全用例 |
| 14 | **隐私 / 泄露**：图片字节进入日志、事件、trace、录制 | 隐私风险 | 事件与调用记录里图片只留占位（尺寸与哈希），不留 base64；测试断言 | 单元测试 |

## 2. 评测数据

1. **拍照集**（`eval/datasets/photos/`，**不入库**——教辅版权）：用户提供的 15 张真实照片，来自四年级下册练习册（北师大版"每日一练"），按练习册页码命名 `raw/p<页码>.jpg`（p008、p009、p014、p021、p023、p033、p044、p047、p053、p065、p069、p079、p088、p090、p100）。覆盖：小数的意义与性质、小数加减 / 乘法与运算律、三角形（含图）、字母表示数、方程、平均数（含表格）、折线 / 条形统计图（图表题）、期末复习；版面包括竖式计算题、比较大小、连线 / 分类、应用题与对话气泡。真实困难都在里面：**纸张透印**（背面的字淡淡透出，几乎每页都有）、倾斜与透视、暗角、"算法整理"示范区、二维码与页眉、相邻页露出的半页。
2. **标注**（`eval/annotation/photos/*.yaml`，不入库；规范 `eval/annotation/photos/guideline.md` 同样不入库，要点见 §4）：每页 = 课时标题 + 题目列表（题号、归一化题面、题型、是否带图、图的关键数据、难度 1～5、知识点候选）。**标注来源**：由评测作者（Claude）逐页看原图独立标注，再由两个与流水线不同的视觉模型（qwen3-vl-plus、qwen3.8-omni-flash，不含被评的 `vision` 角色）独立转写做**交叉核对**，分歧逐条回看原图裁决；**未做人工逐字复核**，已知风险是标注者与被评模型都会读错同一处极细的笔画——因此 B4 的绝对值按"含标注噪声"解释，并请用户抽检（见 §5）。
3. **变体集**（`eval/datasets/photos/variants/`，程序生成，随机种子固定）：对每张真实照片施加一种扰动，沿用其标注——旋转 6～12°、透视、高斯模糊、低光、过曝反光、局部遮挡（手指 / 阴影）、缩小到 800px 长边、叠加手写笔迹（模拟学生作答）。每张源图抽 2～3 种，共约 40 张。
4. **负例集**（`eval/datasets/photos/negatives/`，程序生成 + 公开合成）：英文文章页、纯文字通知（非数学）、空白页、全黑图、严重模糊的数学页、与数学无关的照片风格图（渐变 / 噪声）、初中内容页（一元二次方程）、只有手写的页。判定要求"不可用 / 超范围"。
5. **端到端用例**（`eval/datasets/cases/photo_cases.yaml`）：照片 + 一句话要求（"照这页再出 5 道""再来 2 道拔高的""出点类似的但别太简单""只要选择题"……），期望：题量、范围来源、与参考题不雷同、边界通过。
6. **测试夹具**（入库）：`backend/tests/fixtures/worksheet.png`——程序绘制的合成"练习页"（无版权），用于单元测试与前端端到端的回放。
7. **划分**：15 页按页码交错分 val（9）/ test（6）；变体随源图。test 只在验收时用一次；据 test 失败样本改动后，要补新的未见页（让用户再拍）。

## 3. 指标与阈值（初版；基线后校准，不为过线改定义）

| 指标 | 定义 | 类别 | 阈值 |
|---|---|---|---|
| **B4** | 转写题级准确率：标注题中，归一化题面与某识别题**完全一致**的比例（最优配对）；同时报告召回、精确、字符错误率（CER，配对题上）与数字序列错误率（配对题里数字序列不同的比例，致命错误） | 目标 | 题级 ≥ 0.85；数字错误 ≤ 0.02 |
| B4 精确 | 识别题中有标注对应的比例（多出的题逐条归因） | 诊断 | ≥ 0.90 |
| **B5** | 知识点映射：题 → 知识点 top-1 / top-3 命中（标注为可接受集合） | 目标 | top-3 ≥ 0.85 |
| B6 | 难度估计平均绝对误差 | 诊断 | ≤ 0.8 |
| P3 | 非题内容（示范 / 透印 / 手写 / 页眉 / 二维码）被当作题的数量 / 页 | 诊断 | ≤ 0.3 |
| P4 | 图题：`has_figure` 正确率 | 诊断 | ≥ 0.90 |
| **P5** | 负例拒识率（判定"不可用 / 超范围"且不产生参考题） | 目标 | ≥ 0.95 |
| **P6** | 真实照片与变体的误拒率 | 目标 | ≤ 0.03 |
| P7 | 低置信召回：转写出错的题里被标为不确定的比例；打扰度：标了不确定的题里其实读对的比例 | 诊断 | 召回 ≥ 0.6；打扰度报告 |
| P8 | 防雷同：端到端交付题中与参考题相似度 ≥ 阈值的比例 | 目标 | ≤ 0.02（确定性检查后应为 0） |
| P9 | 照片 + 一句话的 Brief 正确率（用例逐项检查） | 目标 | ≥ 0.90 |
| D-photo | 单张照片识别时延（含预处理）p50 / p95 | 目标 | ≤ 15s / ≤ 25s |
| 成本 | 单张照片的识别成本 | 诊断 | 记录 |

## 4. 实现策略（先写下来，实现后对账）

1. **预处理**（`perception/`，确定性）：按 EXIF 转正；长边缩放到上限（默认 1600px，消融 1024 / 1600 / 2200）；统一转 JPEG；质量指标（清晰度——拉普拉斯方差、亮度均值、对比度、有效尺寸）。**只在极端情况下确定性拒绝**（几乎全黑 / 全白 / 小于 200px），其余质量问题只生成"提示"交给模型与教师判断——门槛放太严会误拒真实照片（P6）。不做自动裁切与透视校正：先看视觉模型对倾斜 / 透视的鲁棒性，有失败再加（不预先加组件）。
2. **`perceive` 阶段**：每张图一次视觉模型调用（多张并行，受并发限制），要求 JSON：页面判定（练习页 / 非数学 / 无题目 / 不可读）、课时标题、题目列表。**提示词的关键约定**（来自第 3 类失败模式）：只转写"需要学生作答的题"，不转写"算法整理 / 示范 / 讲解"区、页眉页脚、二维码、手写作答；**纸张背面透出的淡淡字迹一律忽略**；一行里的多道口算各算一题；公式用纯文本（× ÷ 分数写 a/b）；数字看不清时给出最可能的读法并在 `uncertain` 里说明；图表题给出类型与关键数据的文字描述；每题给 `topic`（教材规范叫法）、`kind`、`difficulty`、`confidence`。输出走结构化校验（带错误反馈重试，沿用网关的 `complete_json`）。
3. **映射与上下文**（确定性 + 检索）：对页面标题与各题 `topic` 去重后做 `kb.search`（并行），得到每题知识点候选（取分数不低于最高分 60% 的前 3 个）；页面级的年级 / 学期 / 课时取标题与题目知识点的众数 / 最晚课时。**学生上下文 = 年级、学期、目标课时、知识点集合、难度分布、题型分布**，进入 Brief：范围来源标 `inferred`；用户一句话里明说的范围优先。
4. **防雷同**：参考题进入创作提示（"学生做过的类似题——借考法与难度，数字与情境必须换"），并在核验里加**确定性新颖度检查**（形状相似度 + 数字集合重合）；与参考题过于相似的新题被拦截并重写（同一套修复机制）。
5. **低置信确认检查点**：任一题 `confidence < 阈值` 或带 `uncertain` 时，运行暂停，向用户展示识别卡片（可就地修改文字，也可删掉某题）；用户确认后按修改后的题继续。全部高置信时不打断，直接继续，卡片在对话里展示。
6. **拒识**：页面判定不是可用练习页（或所有题被过滤为空）→ 不进入出题，回复教师语言的原因与下一步建议；若同时有文字要求，仍可按文字出题（"这张图看不清，已按您的文字要求出题"）。
7. **隐私**：图片只以 data URI 进入模型请求；`llm.call` 事件与调用记录里的图片替换为占位（尺寸 + 哈希）；录制（cassette）的键是请求哈希，不含图片字节。
8. **特性开关**（消融）：`perceive.preprocess`（预处理）、`perceive.topic_search`（每题 `topic` 检索；关则只用页面标题）、`perceive.confirm`（低置信检查点）、`perceive.novelty`（防雷同确定性检查）、`perceive.references_in_prompt`（参考题进入写题提示）。首轮消融在本里程碑内完成。
9. **模型选型**（`vision` 角色）：候选 qwen3.8-flash、qwen3-vl-plus、qwen3-vl-flash、qwen3.8-omni-flash、qwen-vl-ocr；先过 B4 下限与 P5 / P6，再比延迟与成本；结果与候选表写入 [design.md](../../docs/design.md)。**独立性**：标注交叉核对用的模型不得是最终选定的 `vision` 模型。

## 5. 基线与结果

> **读数前先看口径**：①15 张真实页在开发中全部用于调提示词与阈值标定，**数字是开发集成绩，不是干净的留出集成绩**；②标注由评测作者独立完成并经两个 Qwen 视觉模型交叉核对（三方在数字上无分歧，分歧只在切分粒度与书写格式），**没有人工逐字复核**；③样本量小（真实页 190 题、变体 35 张），置信区间约 ±3 个百分点，**小于此的差异不能当作结论**；④评测定义的调整记录在 [CHANGELOG](../CHANGELOG.md)（据首轮结果调整过 `p053` 的标注粒度与归一化规则，对所有模型一视同仁）。

### 5.1 模型对比（vision 角色，15 张真实页，提示词 v2，1600px）

| 模型 | B4 题级一致 | 召回 | 精确 | 每页多出的题 | 数字错误 | B5 top-3 | 延迟 p50 |
|---|---|---|---|---|---|---|---|
| **qwen3.8-flash（选用）** | 0.955 | 0.965 | 0.965 | 0.47 | 0.010 | 0.906 | 约 6s |
| qwen3.8-omni-flash | 0.955 | 0.975 | 0.990 | 0.13 | 0.015 | 0.892 | 约 6s |
| qwen3-vl-plus | 0.920 | 0.955 | 0.905 | 1.33 | 0 | 0.863 | 4～14s |
| qwen3-vl-flash | 0.884 | 0.884 | 0.772 | 3.47 | 0 | 0.784 | 5～14s |

flash 与 omni 分不出高下；**选 flash**：价格已知且最低（¥0.0024 / 页），且 omni 是标注交叉核对用的模型，不能同时是被评对象（独立性规则，D51）。vl-flash 常把一道题拆碎。首轮（提示词 v1）B4 为 0.864、v2 之后 0.955（教训见 5.5）。

### 5.3 端到端：照片 + 一句话（8 个用例，`photo-e2e`）

| 配置 | P9 Brief 符合预期 | **P8 翻版率** | 交付率 | 题与该页知识点有交集 | p50 / 总成本 |
|---|---|---|---|---|---|
| 全部开启（档位 4:4:2） | 1.000 | **0** | 1.000 | 0.583 | 44s / ¥0.48 |
| 全部开启（档位 3:4:3，PRD 之前的默认） | 1.000 | 0 | 1.000 | 0.556 | 40s / ¥0.46 |
| 关 `perceive.novelty` | 1.000 | 0 | 1.000 | 0.556 | 43s / ¥0.47 |
| 关 `perceive.references_in_prompt` | 1.000 | 0 | 1.000 | 0.618 | 42s / ¥0.47 |

### 5.5 过程中发现并修的问题（评测先行的收获）

1. **首轮 B4 只有 0.864**，看逐页明细才发现不是读错数字（数字错误 0），而是**切分粒度**：连线题被切成 6 道、"分一分"题被切成 5 道、统计图下的小问被拆开，以及页面下半的带图题被漏掉。修在提示词（分组规则 + "输出前从页面底部往上自查" + 图中气泡属于题面）而不是放宽评测：v2 之后 0.955。
2. **P3 每页多出的题 0.40（> 0.3）仍未达标**：看到的多出项是：把示范区的步骤（`p047` 缩小图里的"先算：80×2.5=□"）、答题框的标签（"方程：[ ]"）或对一道题的改写另列成题。每页不到半道，且在核对卡片里一眼可见，未再加规则（不预先加组件）；留作后续观察。
3. **模型自报"看不清"不可靠**（P7 召回 0）→ 确定性画质判断（D53）；阈值用变体集标定，真实照片 0/15 误报、劣化变体 13/13 命中。
4. **后处理的归一化**：`x=( )位` 与 `x ( )位`、行内 `$x$`、书写横线、分隔符被判成"读错"，让所有模型在同样的地方失分；这些不影响题意，已在评测归一化里统一（对所有模型同样适用，见 CHANGELOG）。
5. **产品层缺口**：PRD 写明"照片扩题默认档位 4:4:2"，实现时一直用的是 3:4:3 → 照片出题时改为 4:4:2（有测试）。

**失败归因**（全部读自逐页明细，不是内容读错——数字、符号几乎都对）：

2. **共享一张图的小问被拆开**（`f061` 第 2 题、`f087` 第 2 题的 (1)(2)(3)）或把一道题的内容改写成"上排算式：……"：提示词的"合并"规则对带图题没有被遵守——这拉低精确率 / 召回，对生成的影响不大（题面内容都在）。

4. B5：`f007` 第 3 题的知识主题被读成"小数的意义"，映射到分数对应关系 / 小数乘整数，标注是"小数数位与计数单位"——真实的映射偏差，6 题。
