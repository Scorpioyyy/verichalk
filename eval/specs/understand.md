# M2 意图理解评测规格

范围：把教师的一句话（及会话上下文）解析成 `Understanding`：**路由**（出题 / 整卷 / 修改 / 追问 / 导出 / 无关）、**Brief**（范围、题量、难度、题型、档位、来源、情境、限制）、**澄清**（只在不问就大概率做错时提问）、**本次假设**。标注规范见 [eval/annotation/understand/guideline.md](../annotation/understand/guideline.md)。

## 1. 失败模式与检测手段

| # | 失败模式 | 用户感受 | 检测手段 | 指标 |
|---|---|---|---|---|
| 1 | 年级 / 学期 / 单元解析错（"四下"当成四上、"第三单元"按 ID 序号找错） | 出的题范围不对 | 字段检查（期望值 vs 解析值） | B1 |
| 2 | 题量 / 难度 / 题型 / 档位 / 情境 / 限制漏解析或错解析 | "我说了要 5 道你给我 10 道" | 字段检查 | B1 |
| 3 | **先验盖过用户明说的意图**（来源标成 inferred / default） | 说了"就要基础题"却出综合题 | `user_fields` 来源检查 | B1-origin |
| 4 | 凭空断言用户没说的字段（幻觉） | "我没说难度你怎么定成 4" | `absent` 检查 | B1-幻觉率 |
| 5 | 主题没映射到正确的知识点 | 出的题不是想要的知识点 | `topics_any`（映射到的知识点名称 / 别名 / 主线含关键词） | B1 |
| 6 | **该问没问**：范围完全缺失却直接出题 | 出了一份用不上的题 | 澄清召回 | B2 |
| 7 | **不该问却问**：信息够用却追问；一次问多个问题 | 烦、效率低 | 澄清精确率；每次提问选项数与问题数检查 | B2 |
| 8 | 路由错：该修改的当成新出题，该拒绝的当成出题 | 已有的题被整体重出 / 乱出题 | 路由准确率；混淆矩阵 | B3 |
| 9 | 范围冲突被静默改掉（"二年级方程题"悄悄改成五年级） | 以为系统听懂了其实没有 | 矛盾类用例必须 `clarify` | B2 |
| 10 | 提示注入 / 无关请求被执行 | 安全与体验 | `offtopic` 路由 + 回复不含系统提示 | B3、G1、G2 |
| 11 | 结构化输出不合法 / 重试多 | 延迟与失败 | schema 重试率 | E5 |
| 12 | 慢：理解阶段拖慢首个反馈 | 等待焦虑 | 阶段 p50 / p95；检索与理解是否并行 | D1、D4 |
| 13 | 模型不可用时整个理解失败 | 无法使用 | 降级到规则解析的用例（模型注入故障） | F3 |

## 2. 评测数据

- **用例集**：`eval/datasets/cases/understand.yaml`，约 140 例，按场景 × 年级 × 明确程度 × 边缘情形分层构造（见 [evaluation.md §3.1](../../docs/evaluation.md)）；每例按规范写期望（含 `absent`、`user_fields`、`clarify`、`route`）。
- **划分**：按分层各取一半为 val / test（`split` 字段）；val 用于开发调参与模型选型，test 只在验收时用一次。
- **标注方式**：用例由"先设定意图、再写出口语化的说法"的方式构造，期望是构造时的已知意图，不需要事后标注；说法的多样性靠人工撰写覆盖（正式 / 口语 / 错别字 / 夹英文 / 省略）。**灵敏度检查**：随机抽 10% 用例用两个不同厂商的模型独立判定期望，与构造期望不一致的条目人工复核（检查规范是否有歧义），结果记入 `eval/CHANGELOG.md`。
- **gold 有效性守卫**：测试保证每个 `topics_any` 关键词在知识库中至少命中一个知识点（防止期望本身不可达）。

## 3. 指标与阈值（初版，基线后校准；不为过线改定义）

| 指标 | 定义 | 验收线（test） |
|---|---|---|
| **B1 字段通过率** | 所有写出的字段检查（值、`topics_any`、`constraints_any`…）通过的比例，按字段切片报告 | ≥ 0.90 |
| B1-origin | `user_fields` 中带 `origin=user` 的比例 | ≥ 0.95 |
| B1-幻觉率 | `absent` 字段被断言为具体值的比例 | ≤ 0.03 |
| **B2 澄清精确率 / 召回** | 提问中确实应该问的比例 / 应该问的用例里实际问了的比例；每次最多 1 个问题、2～6 个选项（选年级时六个年级各一个；结构检查） | P ≥ 0.85，R ≥ 0.80 |
| B2-占比 | 提问的轮次占全部轮次 | ≤ 0.15 |
| **B3 路由准确率** | 路由等于期望的比例 | ≥ 0.95 |
| E5 | 结构化输出重试率 | ≤ 0.03 |
| D | 理解阶段（含并行检索）p50 / p95 | p50 ≤ 2.5s，p95 ≤ 5s（本机跨境网络下的暂定值） |
| F3 | 注入模型故障时降级到规则解析仍返回合法 Brief | 100% |

动作：B1 / B2 / B3 不达标 → 按失败类别占比从大到小处理：先看是提示词（调示例与定义）、字段映射（单元 / 知识点解析代码）、还是规范本身有歧义（改规范并记录）；**不在评测集里删用例过线**。

## 4. 基线

先用最简单的方法跑一遍并记录（实现前）：**规则解析**（正则 + 关键词 + chalkbase 检索），无模型调用。之后每个改进都对比基线与上一版：

1. 基线：规则解析（特性开关 `understand.llm` 关闭）；
2. 模型版：同一 val 集上对比候选 `fast` 角色模型（qwen3.8-flash、qwen3.7-flash、deepseek-v4.1-flash）；
3. 消融：①检索并行 vs 串行（延迟）；②示例（few-shot）段是否必要；③上下文（上一轮 Brief）是否必要；④澄清策略段是否必要。

实时延迟（真实模型，并发 8，已预热）：理解阶段 p50 1.48～1.99s，p95 2.8～3.9s。**所有验收线均达到**（fresh 的单集澄清召回 0.875 ≥ 0.80；B1 ≥ 0.90，B1-origin ≥ 0.95，幻觉率 ≤ 0.03，B2 精确率 ≥ 0.85 / 召回 ≥ 0.80，B3 ≥ 0.95，p50 ≤ 2.5s）。完整报告见 `eval/reports/`（`*_understand_*.md`、`ablation_understand_*.md`），回放回归见 `backend/tests/test_eval_understand.py`。

**读数时必须注意的事（诚实记录）**：

1. **作者集区分度不足**：作者撰写的集合上，规则基线与模型版 B1 只差约 0.01（置信区间重叠），因为规则与用例出自同一作者、说法规整。真正的差异在**换说法集**与**新留出集**上：规则基线的路由准确率掉到 0.81～0.94、澄清召回 0～0.375，模型版保持 ≥ 0.97 / 1.0。这就是补充换说法集的原因（见 eval/CHANGELOG.md）。
2. **test 划分不是干净的留出集**：第一次验收（`understand` test，提示词 v2、未做主题重检索）的结果是 B1 0.979、B3 0.973、澄清精确率 1.0、**澄清召回 0.667（4/6）**，其中澄清召回未过线（小样本，区间 0.30–0.90）；换说法集 test 的延迟 p50 2.8s 当时超线（后来确认是一次性冷连接与当时接口波动，已用预热消除）。随后我查看了这些失败样本并做了**通用**修复（提示词补充"负数、方程等属于小学"；主题与检索结果不一致时按主题重检索；范围冲突改用"该主题在知识库里最早出现的年级"判断），之后上表的数字属于"事后修复"，不再是干净的留出。为此补充了新的留出集 `understand_fresh`（42 例）：它在修复之后才第一次被系统看到（首次结果：B1 1.000，澄清召回 0.75，之后又据其中的冲突漏检改进了冲突判断并重录）。**下一个里程碑起，验收前再补一批新的未见用例。**
3. **澄清召回的小样本问题**：每个集合里"应当澄清"的用例只有 6～8 条。合并三个 test / fresh 集合（作者 test + 换说法 test + fresh）：精确率 21/21，召回 21/22 = 0.955（最终录制）；首次验收时的合并值为精确率 0.952、召回 0.909。fresh 上仅剩的 1 条漏问是"一年级的乘法分配律"这类模型把明显的荒谬输入判成 offtopic 的情形。

### 5.2 模型选型（`fast` 角色，val，提示词 v2）

| 模型 | B1（作者 / 换说法） | B1-origin | 幻觉率 | B3 | 理解阶段 p50 |
|---|---|---|---|---|---|
| qwen3.8-flash | 0.963 / 0.978 | 0.973 / 0.980 | 0.000 / 0.003 | 0.974 / 0.988 | 2.15s |
| qwen3.7-flash | 0.959 / 0.967 | 0.947 / 0.950 | 0.003 / 0.008 | 0.987 / 1.000 | 1.85s |
| **deepseek-v4.1-flash** | 0.968 / 0.978 | 0.967 / 0.975 | 0.000 / 0.003 | 0.974 / 1.000 | **1.6s** |

三者质量在置信区间内无差别，按决策规则（先过闸门，再选延迟成本最优）选 deepseek-v4.1-flash。注意：换说法集由 deepseek 改写，对它可能有轻微偏向；作者集上三者持平。

### 5.3 消融

**噪声底**：温度 0.3 下，同一配置重复运行，B1 相差约 ±0.005～0.01，来源准确率约 ±0.01，延迟 ±100ms；**单次对比差异小于这个量级的不能下结论**，需要重复。消融均使用独立的录制命名空间（`*_ablate`），不覆盖黄金录制。报告：`eval/reports/ablation_understand_*.md`。

作者集 val（n=70），一次运行，全开 B1 0.968 / 来源 0.967 / 幻觉 0.000 / B2 精确 1.0 召回 1.0 / B3 0.974：

| 关闭的模块 | B1 | 来源 | B2 精确率 | B3 | 延迟 p50 | 成本 |
|---|---|---|---|---|---|---|
| A/A 噪声参照 | 0.963 | 0.960 | 1.0 | 0.974 | +91ms | 0 |
| `understand.context`（会话上下文） | 0.959 | 0.973 | **0.700** | **0.923** | +166ms | 0 |
| `understand.fewshot`（示例段） | 0.986 | 0.967 | 1.0 | 0.974 | +66ms | **−24%** |
| `understand.parallel_search`（并行检索） | 0.968 | 0.967 | 1.0 | 0.974 | +43ms | 0 |
| `understand.topic_research`（主题重检索） | 0.963 | 0.960 | 1.0 | 0.974 | −1ms | 0 |
| `understand.llm`（模型本身 = 规则基线） | 0.963 | 0.980 | 0.800 | 0.949 | **−1280ms** | −100% |

换说法集 val（n=85），示例段重复三次（全开 来源 0.970 / 0.975 / 0.975；关闭后 **0.915 / 0.945 / 0.940**，B1 反而 +0.008 / +0.011，幻觉率相当）；模型 vs 规则：B3 1.000 vs 0.906，澄清召回 1.0 vs 0.125，B1 0.978 vs 0.929，幻觉 0.003 vs 0.028。

| 模块 | 结论 |
|---|---|
| `understand.context` | **保留**：关掉后澄清精确率 1.0→0.70、路由 0.974→0.923。多轮必需 |
| `understand.llm` | **保留**，规则作为降级与基线：自然口吻下规则的路由 / 澄清召回明显更差 |
| `understand.parallel_search` | **保留**：热缓存下差异在噪声内；**冷缓存（每个查询都要算向量）下 p50 1.40s→1.78s（+370ms，三轮一致）** |
| `understand.fewshot` | **保留，证据混合**：换说法集上来源准确率稳定 +0.03～0.055（三次重复一致），作者集上无差异（单次曾见 +0.04，重复后消失），字段通过率略降 0.01；成本 +24%（约 ¥0.0001 / 次，缓存命中后很低）。来源准确率是"先验不得盖过用户明说的意图"的关键保障，故保留；若 M3 的提示词继续变长，需重新评估 |
| `understand.topic_research` | **保留，证据偏弱**：val 集无差异；test 三个集 B1 +0.006 / +0.011 / ±0；延迟中性；只在检索与主题对不上时才多搜一次，代价几乎为零。用未来的新留出集继续复核，若仍无显著收益则删除 |

### 5.4 失败类别（最终，剩余的少量错误）

- 档位 / 来源的边界：用户措辞隐含但未明说的档位（"寒假复习"是否算综合）、"最基础的那种"是否算课本题（`source`）——属于规范本身的灰色地带。
- 跨年级主题的年级推断：同一主题在多个年级出现时，按最高分命中的年级推断，有时与"首次引入"的年级不同（如折线统计图）。
- 路由的真歧义："改成六年级的"（已有试卷时是修改还是重出）。
