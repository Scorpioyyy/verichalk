# M1 基建评测规格

范围：配置与密钥、领域模型、事件 / trace 与存储、LLM 网关、知识层适配、沙箱、阶段 / 管线框架、API 骨架、指标计算、评测框架。这些模块不产生教师可见的"题"，因此评测的对象是**契约与可观测性**：框架若不可靠，后面所有阶段的评测都不可信。

## 1. 失败模式与检测手段

| # | 失败模式 | 后果 | 检测手段 | 类型 |
|---|---|---|---|---|
| 1 | 业务代码绕过网关 / 沙箱 / 知识层，或违反分层依赖 | 指标缺口、不可替换 | `test_architecture`：AST 扫描分层与禁用导入 | 不变量 |
| 2 | span 未闭合、孤儿 span、seq 不连续、事件乱序 | 调试台与指标失真 | `trace_completeness`：对每个运行检查 span 树与 seq；异常（含取消）路径也要闭合 | 不变量 |
| 3 | 流式聚合错误：usage 丢失、`cached_tokens` 未记录、TTFT 为空 | E2、D5 指标不可用 | 对假传输层（含 usage 末块、无 usage、分片边界）的单元测试；对真实模型的 `probe` | 不变量 + 探针 |
| 4 | 录制回放不一致：同一请求回放得到不同结果；键碰撞；录制泄漏密钥 | 回归不可信 | 录制 → 回放往返测试；键对 messages / 参数 / 模型敏感；录制文件密钥扫描 | 不变量 |
| 5 | 密钥或端点主机名出现在日志、trace、事件、录制、错误文本 | 安全事故 | 日志脱敏测试；全部事件序列化后正则扫描；错误文本脱敏测试 | 不变量 |
| 6 | 沙箱被绕过（import、open、dunder、无限循环、内存炸、浮点字面量） | 任意代码执行 | 对抗用例集（≥30 条）：每条必须被拒或被超时终止；正常求解程序全部通过 | 不变量 |
| 7 | SSE 断线续传丢事件或重复；运行结束后连接不关闭；代理缓冲 | 进度不可靠 | 对 `Last-Event-ID` 的集成测试：中途断开再续传，事件序列与全量一致 | 不变量 |
| 8 | 取消不生效 / 取消后仍产生事件 / 取消泄漏 span | 浪费成本 | 取消测试：取消后 ≤2s 无新事件，所有 span 闭合 | 不变量 |
| 9 | 阶段异常导致运行永久 `running`（服务重启遗留） | 前端卡死 | 启动时把遗留 `running` 置为 `failed(interrupted)` 的测试 | 不变量 |
| 10 | 知识层适配返回体过大（撑爆 LLM 上下文）或丢字段 | 成本与质量 | 返回体 token 估计上限测试；与 chalkbase 原始结果的字段对照 | 不变量 |
| 11 | 指标计算与事件不一致（如 cached 比率分母错） | 指标误导 | 对构造 trace 的黄金值单元测试（手算期望值） | 不变量 |
| 12 | 预算保护失效，单次运行成本失控 | 费用 | 预算超限必定触发降级 / 终止的测试 | 不变量 |
| 13 | 框架开销过大（每事件持久化拖慢运行） | 延迟 | 基线：10k 事件写入耗时、空管线端到端开销 | 基线 |

## 2. 评测数据

- 不需要标注数据；用手工构造的假传输层、构造的 trace、对抗沙箱用例集、`smoke` 用例（`eval/datasets/cases/smoke.yaml`）。
- 真实模型探针（`scripts/probe_llm.py`）：对每个候选模型测 TTFT、总时长、输出速度、`cached_tokens` 行为（重复前缀 ×2），结果写入 `eval/reports/m1_probe.md`，作为 D5 / E2 的基线。

## 3. 阈值与动作

| 项 | 门槛 | 不达标时 |
|---|---|---|
| 全部不变量 | 100% 通过 | 回到对应模块修复，不放行进入 M2 |
| `smoke` 用例（replay） | trace 完整度 F6 = 0；运行成功率 100% | 同上 |
| 框架开销 | 空管线端到端 p95 ≤ 50ms（不含网络）；10k 事件写入 ≤ 3s | 优化批量写入 / 索引 |
| 探针 | 每个候选模型拿到有效的 TTFT、usage、cached_tokens | 记录模型能力缺口，更新 D10 |

## 4. 基线

在实现前先用最简方案跑一遍并记录：①SQLite 逐事件提交的 10k 事件写入耗时；②空协程管线的事件开销。之后每次优化与此对比。基线与探针结果写入 `eval/reports/m1_baseline.md`。
