# 指标体系

> 一套指标覆盖产品效果、交互体验、性能、成本与工程可靠性，并分清主次。所有指标有唯一编号、明确定义、数据来源与初版目标。目标值**暂定**：按 [evaluation.md](evaluation.md) 的纪律，先跑出基线再校准，不为过线改定义。

## 1. 原则

1. **主次分明。** 指标分五层：**北极星**（只有一个，决定"做得好不好"）、**闸门**（不达标不发布）、**目标**（持续优化）、**护栏**（预算与副作用上限）、**诊断**（定位问题用，不单独追求）。
2. **指标由 trace 算出。** 线上监控、离线评测、调试台看到的是同一份事件日志、同一套计算函数（`verichalk.metrics`），不存在"评测一套、线上一套"。
3. **质量由三类证据支撑**：确定性检查（D，不依赖模型）、标注数据（H，多模型交叉标注 + 抽样复核）、模型判官（J，需与标注数据校准，且判官模型不得与被评对象同源）。
4. **每个比例类指标报告 Wilson 置信区间；** 按档位 / 年级 / 任务类型 / 模型分层报告，防止总体均值掩盖局部退化。
5. **一个指标变差必须能归因到阶段。** 见 §8 的归因树。

## 2. 指标树（主次关系）

```
北极星  A1 可直接使用率
 ├─ 闸门   A2 答案正确率（已核验标签的精确率）   A3 不超纲率
 ├─ 目标   A4 需求满足度   A5 新颖度   A6 题面质量
 ├─ 目标   B* 理解（意图 / 澄清 / 拍照）   C1 编辑成功率
 ├─ 目标   D1 首反馈   D2 首题时间   D3 端到端时长
 ├─ 闸门   F1 运行成功率   C4 导出成功率
 ├─ 护栏   E1 单题成本   E3 调用放大倍数   D3 时长上限
 └─ 诊断   D4 阶段延迟  D5 模型延迟  E2 缓存命中  E4 修复率  F2–F6  其余
```

## 3. 质量（A 组，产品侧核心）

| ID | 指标 | 定义 | 来源 | 层级 | 初版目标 |
|---|---|---|---|---|---|
| **A1** | **可直接使用率** | 交付给用户的题中，满足"教师无需修改即可使用"的比例。判据 = 答案正确 ∧ 不超纲 ∧ 题意明确 ∧ 与需求相符 ∧ 语言适龄（逐项 rubric，全部通过才算） | J + H 校准 | **北极星** | 基线后设；暂定 ≥ 0.80 |
| **A2** | **答案正确率** | (a) *已核验* 标签的精确率 = 标"已核验"的题中答案真正确的比例；(b) 全部交付题的答案正确率。用独立标注（程序求解 + 人工抽检）为准 | D + H | **闸门** | (a) ≥ 0.99；(b) ≥ 0.97 |
| **A3** | **不超纲率** | 交付题中 `check_item` 判 `in` 的比例；`out` 的交付比例；`borderline` 交付时必须带提示 | D（ChalkBase） | **闸门** | `out` ≤ 0.02；`in`+提示的`borderline` ≥ 0.98 |
| A4 | 需求满足度 | 对结构化期望逐项判定：题量、知识点覆盖、难度分布（EMD 距离）、档位、题型、风格、用户限制（如"数字不大"）。每条用例通过比例 | D + J | 目标 | ≥ 0.90 |
| A5 | 新颖度 | (a) 教材 / 上传题雷同率：与教材习题或上传题的最大相似度 ≥ θ 的比例（`novel` 来源）；(b) 套内重复率；(c) 综合档"真综合"比例：解答确实用到 ≥2 个所声称的知识点 | D + J | 目标 | (a) ≤ 0.05；(b) ≤ 0.03；(c) ≥ 0.80 |
| A6 | 题面质量 | 判官 1～5 分：题意清晰无歧义、语言适龄、情境真实合理、数据合理（如价格、人数不荒谬）。歧义标记率单列 | J + H 校准 | 目标 | 均分 ≥ 4.0；歧义率 ≤ 0.03 |
| A7 | 核验覆盖率 | 交付题中完成 ≥2 路独立核验的比例 | T | 诊断 | ≥ 0.70（成本允许时更高） |

**A1 rubric 的各项与 A2–A6 重叠，A1 是它们的合取**——这样 A1 既是综合指标，又能分解归因。

## 4. 理解与交互（B / C 组）

| ID | 指标 | 定义 | 来源 | 层级 | 初版目标 |
|---|---|---|---|---|---|
| B1 | 意图解析质量 | 三项：**字段通过率**（评测集里写出的字段检查通过的比例，按字段切片）、**来源准确率**（用户明说的字段必须标为 `origin=user`，防止先验盖过用户意图）、**幻觉率**（用户没说的字段被断言为具体值的比例）。定义变更见 eval/CHANGELOG.md | H | 目标 | 字段 ≥ 0.90；来源 ≥ 0.95；幻觉 ≤ 0.03 |
| B2 | 澄清质量 | 精确率 = 提问中确实需要提问的比例；召回 = 需要提问的用例里实际提问的比例；澄清轮次占比。澄清只在**范围缺失**或**范围冲突**时触发，由确定性代码判断 | H | 目标 | P ≥ 0.85，R ≥ 0.80，占比 ≤ 0.15 |
| B3 | 路由准确率 | 一轮输入被分到正确动作（生成 / 编辑 / 追问 / 导出 / 澄清应答 / 越界） | H | 诊断 | ≥ 0.95 |
| B4 | 拍照转写准确率 | 题级：归一化后题面完全一致比例；字符级：CER；数字与单位错误单列（致命错误） | H | 目标 | 题级 ≥ 0.85；数字错误 ≤ 0.02 |
| B5 | 知识点映射命中 | 照片中的题 → 知识点：top-1 / top-3 命中率 | H | 目标 | top-3 ≥ 0.85 |
| B6 | 难度估计误差 | 估计难度与标注难度的平均绝对误差 | H | 诊断 | ≤ 0.8 |
| **C1** | 编辑成功率 | 自然语言编辑后：①请求的改动已体现 ②未改动的部分保持不变（无附带破坏）③复核通过 | D + J | 目标 | ≥ 0.90 |
| C2 | 手改复核延迟 | 用户手改到核验状态更新的时间 p50 / p95 | T | 诊断 | p95 ≤ 3s |
| C3 | 满意轮次 | 一个会话到用户导出前的修改 / 重出次数（线上）；离线用脚本化用户模拟 | T | 诊断 | 持续下降 |
| **C4** | 导出成功率与保真 | 成功率；人工抽检公式 / 版面错乱率 | T + H | **闸门** | 成功率 ≥ 0.99；错乱率 ≤ 0.02 |

## 5. 性能（D 组，用户体验侧）

延迟全部按**任务类型**分层（单点 5 题、综合 3 题、拍照 +5 题、整卷、编辑、导出），报告 p50 / p95。

| ID | 指标 | 定义 | 层级 | 初版目标（p50 / p95） |
|---|---|---|---|---|
| D1 | 首反馈延迟（TTFB） | 提交到收到首个事件（"已收到，正在理解"） | 目标 | 0.5s / 1.5s |
| D2 | 首题时间（TTFI） | 提交到首道**通过核验**的题上屏 | 目标 | 25s / 45s |
| D3 | 端到端时长 | 单点 5 题到全部上屏 | 目标 / 护栏 | 60s / 100s |
| D4 | 阶段延迟 | 每个阶段（理解、感知、规划、生成、核验、修复、装配、导出）的 p50 / p95 与占端到端的比例（关键路径分析） | 诊断 | 按基线 |
| D5 | 模型调用延迟 | 按模型角色与模型：TTFT、总时长、输出速度（token/s） | 诊断 | 按基线 |
| D6 | 并行效率 | 逐题并行度的实际加速比（串行时长之和 / 墙钟时长） | 诊断 | ≥ 0.6 × 并发上限 |
| — | 专项 | 蓝图 ≤ 20s；单题编辑 ≤ 12s；导出 PDF ≤ 8s；单张照片识别 ≤ 15s（均为 p50） | 目标 | — |

## 6. 成本与缓存（E 组，工程侧核心）

| ID | 指标 | 定义 | 层级 | 初版目标 |
|---|---|---|---|---|
| E1 | 单题 / 单卷成本 | 总 token × 单价（输入未命中 / 命中 / 输出分开计价），按任务类型分层 | 护栏 | 基线后设上限 |
| **E2** | **KV 缓存命中率** | `cached_tokens / prompt_tokens`，按调用、阶段、模型、会话轮次汇总；另报"前缀稳定度" = 实际命中 / 理论可命中（静态前缀长度）。目的是发现提示词因动态内容过早出现而破坏前缀 | 诊断（强监控） | 多轮会话 ≥ 0.60；同阶段重复调用 ≥ 0.80 |
| E3 | 调用放大倍数 | 每道交付题平均模型调用数、总 token 与"最小必要 token"之比 | 护栏 | ≤ 基线 × 1.2 |
| E4 | 修复率与废弃率 | 需要 ≥1 次修复的题占比；最终被废弃的题占比；废弃题消耗的 token 占比（浪费） | 诊断 | 废弃 token 占比 ≤ 0.15 |
| E5 | 结构化输出失败率 | JSON 解析 / schema 校验失败而重试的调用占比 | 诊断 | ≤ 0.03 |

## 7. 可靠性与安全（F / G 组）

| ID | 指标 | 定义 | 层级 | 初版目标 |
|---|---|---|---|---|
| **F1** | 运行成功率 | 无未处理异常、给出用户可理解结果（含"礼貌拒绝 / 澄清"）的运行占比 | **闸门** | ≥ 0.99 |
| F2 | 模型错误率 | 超时、429、5xx、内容审核拦截占调用比；重试成功率；兜底触发率 | 诊断 | 按基线 |
| F3 | 降级率 | 触发降级（跳过盲解、改用较小模型、降级为词法检索）的运行占比 | 诊断 | 按基线，且 UI 须告知 |
| F4 | 取消响应 | 用户点"停止"到停止产生新事件 | 诊断 | ≤ 2s |
| F5 | 恢复能力 | 服务重启 / 连接中断后，会话与试卷不丢；SSE 断线可续传 | 闸门（基础） | 100% |
| F6 | trace 完整度 | 每个运行都有完整 span 树，缺失 / 孤儿 span 数 | 闸门（基础） | 0 |
| G1 | 提示注入鲁棒性 | 图片 / 文本中含指令（"忽略以上要求"）时，不改变行为 | 闸门（基础） | 评测集 100% |
| G2 | 越界请求处理 | 非数学、超出小学、有害请求被礼貌拒绝 / 重定向的比例 | 目标 | ≥ 0.98 |

## 8. 归因树：指标变差时看哪里

| 现象 | 优先检查 |
|---|---|
| A2 下降（答案错） | 核验是否被跳过（A7）；求解程序与题面是否不一致；盲解模型变化；输入含歧义（A6 歧义率） |
| A3 下降（超纲） | 特征抽取（`extract_features`）漏项；Plan 阶段的知识范围（`learned_before`）；ChalkBase 边界本身的宽松处（已知局限） |
| A4 下降（不符合需求） | 意图解析（B1）；蓝图覆盖；修复循环是否丢约束 |
| A5 下降（雷同 / 不新） | 生成提示里教材示例过多（"抄"）；档位先验失效；温度；雷同阈值 |
| D2 变慢 | 关键路径：是否串行化了本可并行的阶段（D6）；模型延迟（D5）；缓存失效（E2） |
| E1 上升 | 修复率（E4）、盲解范围、提示长度、缓存命中（E2） |
| F1 下降 | 模型错误（F2）、结构化输出失败（E5）、沙箱超时 |

## 9. 数据采集与计算

- 采集：事件日志（见 [architecture.md §6](architecture.md)）是唯一来源；模型调用的 `usage`（含 `cached_tokens`）、首字时间、总时长、重试次数、成本在调用 span 上记录。
- 计算：`verichalk.metrics` 提供 `compute(run_traces) -> MetricSet`，输入是一批运行的 trace 与（可选）标注，输出是带置信区间的指标与分层切片。
- 呈现：①调试台"指标"页（线上与离线共用）；②`eval/reports/` 下的评测报告；③`eval/reports/history.jsonl` 追加记录，用于看趋势。
- 判官校准：每个判官（A1 / A6 / A4 / A5c / C1）都有一份人工 / 多模型标注的校准集，报告判官与标注的一致率（Cohen's κ）；κ 低于 0.6 的判官结论只作参考。
