# M3a 规划（plan）评测规格

范围：把 `Brief`（已由 M2 理解）变成 **Blueprint**——每道题的 `ItemSpec`：用哪些知识点（单点 / 组合）、什么档位与难度、什么题型、什么情境与问法、数值范围。这一步决定了题目"新不新、综合得自不自然、是否在已学范围内、整套是否不重复"，创作与核验（[produce.md](produce.md)）只负责把规格变成**对的**题。

设计依据：[architecture §5.2](../../docs/architecture.md)、[D20](../../docs/design.md)（确定性优先，LLM 只做选择与创作）。

## 1. 失败模式与检测手段

| # | 失败模式 | 用户感受 | 检测手段 | 指标 |
|---|---|---|---|---|
| 1 | **超出已学范围**：规格里含目标课时之后才学的知识点（四下出小数除法） | 学生没学过 | 确定性：知识点首次引入课时 ≤ 目标课时（`learned_before`） | P1（硬不变量） |
| 2 | **组合牵强**：把毫无关系的知识点硬拼（"圆柱体积 + 钟表"） | 题目读起来别扭，不是真综合 | 与教材真实跨点题的吻合（留出召回）；判官自然度 | P2、P5 |
| 3 | **组合平庸**：只会给出教材里本来就有的搭配，没有创新 | 和练习册一样 | 选中组合里"教材未出现过的自然组合"占比 | P2b |
| 4 | **伪综合**：规格声称 2 个知识点，实际用不上其一 | 综合题名不副实 | 规格要求每个知识点写明"在解答中的作用"；创作后判官核对（produce 的 A5c） | A5c |
| 5 | **规格与 Brief 不符**：题量 / 档位 / 难度 / 题型 / 知识点覆盖不对 | "我要 5 道你给我 4 道" | 确定性结构检查 | P3 |
| 6 | **情境重复或不贴年级**：5 道题全是"超市"；一年级出"股票" | 千篇一律 | 情境多样性；情境与年级匹配（情境库的年级与数值范围） | P4 |
| 7 | **丢掉用户限定**：用户说"和买东西有关""数字别太大"，规格里没体现 | 意图没落地 | 确定性：用户明说的情境 / 限制 100% 出现在规格里 | P4b |
| 8 | **复习请求没有复习**：说"期末复习，穿插以前学的"，规格全是当前内容 | 没有螺旋复习 | 复习类请求里来自 `review_candidates` 的知识点占比 | P7 |
| 9 | **范围过宽时一直考同一个点** | 覆盖偏窄 | 范围内知识点 ≥ 题量时，规格中不同知识点数 / 题量 | P3 |
| 10 | **规划模型失败 / 输出非法** | 整个请求失败 | 注入故障：降级为确定性蓝图仍合法 | F3 |
| 11 | 慢：规划拖慢首题 | 等待焦虑 | 阶段 p50 / p95 | D4 |

## 2. 评测数据

1. **留出的教材跨点题（P2，客观、无需标注）**：知识库里 376 张题型卡片带 `secondary_knowledge_point_ids`，即教材真实出现过的"跨知识点"题，去重得 303 个知识点对。评测时把这些"共现"信号从图索引里**拿掉**，以其中一个知识点为锚点，看组合挖掘能否把另一个排进前 k。**诚实说明**：知识库的关系边在构建时部分用到了习题共现，所以这不是完全独立的留出；它衡量的是"仅凭图结构与教学位置，能否复现教材里真实的搭配"，而创新性（教材没有的自然搭配）另由 P2b / P5 衡量。
2. **范围合法性（P1，属性测试）**：对 12 册每个单元末课时作为目标课时、每个领域，组合挖掘与规划的输出逐一检查（确定性、零成本，进 pytest）。
3. **蓝图用例（P3、P4、P7 等）**：并入 [produce.md §2](produce.md) 的端到端用例集（自然语言请求 → 理解 → 规划 → 创作），规划阶段的检查读 `Blueprint` 快照，不需要额外的数据。
4. **组合自然度判官集（P5）**：对若干范围（年级 × 领域）分别用**组合挖掘**、**随机已学搭配**、**同主题近邻**产出组合，混在一起交给与规划模型**不同源**的判官打 1～5 分（"能否在一道小学数学题里自然同时用到这两项知识"），盲评、顺序随机。判官校准：从中抽 40 对由我按同一规范标注，报告一致率（见 produce.md §4 判官校准）。

## 3. 指标与阈值（初版；基线后校准，不为过线改定义）

| 指标 | 定义 | 验收线 |
|---|---|---|
| **P1 范围合法率** | 规格里知识点全在已学范围内的比例 | **= 100%**（硬不变量） |
| **P2 留出召回@k** | 去掉共现信号后，教材真实搭配的另一端出现在前 k 个候选中的比例（k = 5、10），按"锚点是否有教材跨点题"分层 | 显著高于随机与"检索近邻"基线（差异的置信区间不含 0）；绝对值 @10 暂定 ≥ 0.40，**基线后校准** |
| P2b 组合新颖率 | 选中的综合组合里"教材共现集合中没有"的比例 | 报告；与 P5 联读（新颖且自然才算好） |
| **P3 蓝图结构通过率** | 题量精确、档位分布与分配一致（±1）、难度在范围内、题型 ⊆ 要求、范围内知识点足够时覆盖不重复 | ≥ 0.98 |
| **P4 情境多样性** | 同一蓝图中不同情境数 / 题量 ≥ 0.8（题量 ≥ 4 时）；同一情境至多 2 题；与年级匹配（数值范围来自情境库） | ≥ 0.95 的蓝图达标 |
| P4b 用户限定保留率 | 用户明说的情境 / 限制（如 `scenes` / `constraints`）在规格里体现的比例 | 100% |
| **P5 组合自然度** | 判官分 ≥ 4 的组合占比（组合挖掘 vs 随机 vs 近邻） | 组合挖掘 ≥ 0.80，且显著高于两个基线 |
| P7 复习占比 | 复习请求中，规格里来自复习候选（目标知识点的已学前置）的知识点占比 | ≥ 1/3 |
| F3 | 注入规划模型故障，降级蓝图仍通过 P1、P3 | 100% |
| D4 | 规划阶段 p50 / p95 | p50 ≤ 8s，p95 ≤ 15s（含一次 `smart` 调用；暂定） |

动作：P1 任何一例失败都是缺陷（先查知识范围解析，再查组合挖掘的过滤）；P2 / P5 不达标 → 先看哪类信号贡献小（见 §5 消融），再调权重（权重在配置里，不写死）；P3 / P4 不达标 → 查分配算法与提示词，**确定性约束优先用代码保证，而不是靠提示词请求模型遵守**。

## 4. 基线

1. **随机已学搭配**：在已学范围内、同领域随机取 2～3 个知识点（P2、P5 的下界）。
2. **检索近邻**：以锚点的名称检索 top-k（`kb.search`）作为"相关知识点"（用户视角下"问系统要相关知识点"的最简方式）。
3. **仅图边**：只用前置 / 递进 / 相关 / 扩展边的距离，不用共现与领域搭配。
4. 规划的整体基线：**确定性蓝图**（`plan.llm` 关闭）：分配算法 + 情境轮换，不调用模型。

## 5. 消融（进入主路径的同一里程碑内完成）

| 开关 | 比较 |
|---|---|
| `plan.combo_miner` | 综合题的知识点由组合挖掘提供 vs 由规划模型自行从检索结果里挑 |
| `plan.llm` | 模型构想情境与问法 vs 确定性分配（情境库轮换） |
| `plan.signal.*`（`cooccur` / `edges` / `domain_mix` / `distance`） | 组合挖掘的各路信号逐一关闭，看 P2 / P5 的变化（评测内部用权重配置而非特性开关） |
| `plan.review` | 复习请求使用 `review_candidates` vs 不用 |

结论写入 design.md（`D<n>`），没有可度量收益的信号 / 模块删除。

## 6. 本规格之外

整卷的蓝图（细目表、覆盖度、分值）属于 M5；本规格只覆盖"一次出 N 道题"的规划。

## 7. 结果（进行中）

- **P2 留出召回（303 个教材跨点对 × 双向 = 606 例，`eval/combo_eval.py`）**：随机已学搭配 0.132@10；教学位置最近邻 0.751@10；组合挖掘（默认权重）0.772@10，把 `edge` 降到 0.6、`proximity` 升到 1.0 后 0.847@10（0.858 为过度调参）。**读数**：教材里真实的跨点搭配 96% 同领域、70% 同单元，所以该指标主要奖励"教学位置接近"，只能当不退步的底线（见 design.md D33）。逐信号消融：去掉 `proximity` 召回下降最多（0.772→0.688），去掉 `edge` 反而上升（0.838），说明关系边对"教材式搭配"的预测力弱，它的价值在复习（前置链）与跨单元综合，要用 P5 / 综合题真综合率评判。
- **跨主题组合的"桥"规则**：要求直接关系边 / 教材共现 / 共同邻居，使 65%～80% 的锚点仍有跨主题候选，去掉"小数加减 × 平移与平行"这类牵强搭配。
- **整学期综合先验**：范围是整学期 / 整年级且没点名知识点、没限定单元时，综合题默认选**同一学期、不同单元、不同主题且有桥**的搭配；限定了单元或知识点，搭档不跨出所限范围（用户意图优先）。
- **P3 / P1**：确定性蓝图的题量精确、范围合法、难度在范围内由单元测试保证（`tests/test_plan_rules.py`、`tests/test_graph.py`）。
- **P5（判官自然度）、P4（情境多样性）、P7**：尚未单独评测；端到端里综合题真综合率 A5(c) 在 base1 为 47/47，但判官较宽松。
