# M6 导出（render + figures）评测规格

范围：把一份 `Paper`（Pandoc Markdown + TeX 数学，插图为 `FigureSpec`）变成教师能直接打印 / 继续编辑的文件：**PDF、Word、Markdown、LaTeX 源码**；并提供首批图形类型的 `FigureSpec → SVG` 渲染。预览与导出同源：前端"试卷视图"直接嵌入 PDF 导出（见 D42），所以这里的保真就是教师看到的保真。

设计依据：[D7](../../docs/design.md)（内容格式）、[D8](../../docs/design.md)（pandoc + Typst，S1 探针已通过）、[D27](../../docs/design.md)（内容规范化）、[D42](../../docs/design.md)（本期决策）。

## 1. 失败模式与检测手段

| # | 失败模式 | 教师感受 | 检测手段 | 指标 |
|---|---|---|---|---|
| 1 | **公式漏转 / 变成普通文本**（`$3.6-1.25 = $`、未闭合的 `$`） | 打印出来一堆 `\frac`、美元符号 | PDF 文本里不得出现 `\` 命令、孤立 `$`；Word 里原生公式对象数 = 内容里的公式数 | X1、X2 |
| 2 | **汉字缺字（豆腐块）** | 关键字符显示成方框 | 对内容出现的每个字符，字体栈里至少一个字体有字形（`missing_glyphs`）；导出时作为警告返回 | X3 |
| 3 | **版面错乱**：选项挤成一团 / 竖排过长、题号错位、跨页把题号与题干拆开、答案空间不足 | 打印后要手工调 | 确定性版面规则（选项列数由最长选项决定、题块不拆页）；人工抽检页面截图 | X4（人工）|
| 4 | **题目 / 答案缺失或错位**：学生版里出现答案；教师版缺解析；题号不连续 | 发给学生泄题 / 丢题 | 学生版全文不得含任何题目的答案串与"解析"字样（属性测试）；题号连续；每道题的题干文本都能在导出文本里找到 | X5 |
| 5 | **分值与总分对不上** | 卷面分数错 | 分区分值合计 = 题目分值之和；总分 = 各区之和；与 `meta.total_score` 不符时警告 | X6 |
| 6 | **插图丢失 / 变形** | 题干说"如图"却没有图 | 内容里的 `![](fig:…)` 数 = 导出文件里的图片数；SVG 渲染确定性（同规格同输出） | X7 |
| 7 | **Word 里公式不能再编辑**（被导成图片或文本） | 在 Word 里没法改 | OMML 对象数 = 公式数；不得有公式图片 | X2 |
| 8 | **导出失败 / 超时 / 崩溃**（特殊字符、超长题、空试卷、空选项） | 点了导出没反应 | 边缘用例集全格式导出；失败给教师可读的原因，不抛堆栈 | **C4（闸门）** |
| 9 | **慢** | 等待焦虑 | 20 题试卷各格式 p50 / p95（预热后） | X8 |
| 10 | **LaTeX 源码不能编译** | 拿到源码用不了 | 本机有 TeX 引擎时实际编译（评测可选项；服务端只生成源码不编译，D8） | X9 |

## 2. 评测数据

`eval/datasets/export/papers.yaml`：手工设计的 `Paper` 用例（覆盖公式密集、分数与小数混排、长题干、选择题选项长短不一、填空横线、带图、带表格、多分区带分值、40 题长卷、纯文字、空选项、含 `$` / `%` / `#` / `_` / `&` 等特殊字符、全角标点、只有一道题、空试卷、`needs_review` 题）。每个用例带 `expect`：页数范围、公式个数、图个数。

另有**真实产出用例**：`eval/cassettes` 里端到端录制的产出（M3 的运行结果）可以直接导出，抽样做人工抽检（不进自动评测，因为内容会随链路变）。

## 3. 指标与阈值

| 指标 | 定义 | 类别 | 阈值 |
|---|---|---|---|
| **C4(a)** | 导出成功率：用例 × 格式 全部产出可打开的文件 | **闸门** | ≥ 0.99（目标 1.00） |
| **C4(b)** | 自动检测到的公式 / 版面错乱率（X1 + X3 + X5 + X6 + X7 的失败占比） | **闸门** | ≤ 0.02（目标 0） |
| X2 | Word 原生公式数 = 公式数的用例占比 | 目标 | = 1.00 |
| X4 | 人工抽检页面截图的错乱数（每次验收看 ≥ 6 页） | 目标 | 0 |
| X8 | 20 题试卷导出延迟 p95（PDF / Word） | 诊断 | ≤ 3s（PDF，预热后）、≤ 2s（Word） |
| X9 | 本机能编译 LaTeX 时，源码编译成功率 | 诊断 | ≥ 0.95 |

阈值不为过线而改；检测器本身有单元测试（构造坏输出确认能抓到）。

## 4. 实现策略（先写下来，实现后对账）

1. **单次 pandoc 调用**：把全卷所有文本片段（标题、题干、选项、答案、解析）用分隔标记拼成一份文档，转一次，再按标记拆开；每次导出只启动一次子进程。填空横线 `____` 与插图引用在转换前换成占位符，转换后换成目标格式的结构。
2. **版面在自有模板里**：PDF 的整体版面（页眉页脚、题号、选项网格、分区标题、答案空间）由 Typst 模板控制；pandoc 只负责片段。
3. **中间视图 `PaperView`**：纯函数把 `Paper + ExportOptions` 变成"该怎样排"的数据（题号、分区编号、分值、哪些字段出现），四种格式共用，所以学生版 / 教师版 / 分值规则只写一处，也只测一处。
4. **字体**：Typst 模板写字体回退栈（Noto Serif/Sans CJK SC → 宋体 / 微软雅黑 → …）；Docker 镜像装 `fonts-noto-cjk`；`missing_glyphs` 在导出时给出警告。
5. **图形**：`FigureSpec → SVG` 是纯函数（无依赖）；PDF 直接嵌 SVG，Word 先栅格化（用 Typst 渲染 PNG）。首批类型按"知识库里依赖图形的题型"定：数轴、条形统计图、几何图形（长方形 / 正方形 / 三角形 / 平行四边形 / 梯形，带边长标注）、方格图（涂色格 / 对称 / 平移）。
6. **预览即导出**：不另做一套分页预览。

## 5. 基线与结果

**基线与验收（2026-10-06，`eval/reports/export_m6_20261006.md`）**：14 份试卷 × 4 格式 × 2 版本 = 120 次导出，C4(a) = 1.000，C4(b) = 0.000，X2 = 1.000，LaTeX 实际编译（X9）全部通过；20 题试卷延迟 PDF p50 约 650ms、Word 约 360ms、LaTeX 约 270ms。

**自动检测抓不到、靠人工看页面发现并已修复的问题**（第一版自动检测就是全绿，所以"全绿"不等于保真，X4 必须有人看）：
- PDF：行内分数是缩小的上标式（改成显示样式）；含分数的选项行距太挤，行与行重叠；学生版作答空白一刀切太大（改为按题型与解析长度三档）。
- Word：公式里的数字被排成斜体（给纯数字 run 补正体标记，并设数学区字体）；分区小标题没加粗；选项表格列宽不等、两列时被 pandoc 当成普通文字（改用等宽管道表）。
- LaTeX：pandoc 的表格代码需要 `\newcounter{none}`，只有真编译才发现（X9 的价值）。
- 实现中发现的环境坑：pandoc 在 Windows 输出 CRLF，会破坏片段分隔，转换后统一归一化。
**已知未处理**：题干里孤立的反斜杠会被 pandoc 当作转义吞掉；Word 里行内分数比 PDF 小（Word 自身的行内公式规则）。
**人工验收工具**：本机 Word 转 PDF（`scripts/docx_to_pdf.ps1`）看真实排版；PDF 用 PyMuPDF 转图。
